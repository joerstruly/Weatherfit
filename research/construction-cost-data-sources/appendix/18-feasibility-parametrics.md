## Model input map (best source, and its weakness)
| Driver | Best public source | Weakness |
|---|---|---|
| Base $/SF or $/unit, multifamily by typology | RAND RRA3743-1 | California only; 2025; mixes prevailing-wage and market-rate |
| Base $/SF, non-residential | UFC 3-701-01 | DoD scope/specs; no retail; must be de-militarized and re-escalated |
| Parking per stall | WGI (above-grade, annual, metro) + UCLA ITS (above/below differential, 17 cities) | WGI full report gated; UCLA is a one-off; both exclude land |
| Location factor | DoD ACF PAX 3.2.1 | Calibrated to DoD scope; irregular updates; RSMeans CCI better-fit but no free extract |
| Escalation to midpoint | AACE 58R-10/68R-11 method + BLS PPI 236500 regional + RLB/T&T/JLL forecasts | No free forward index by metro; forecasts disagree ~1.5 pts = 3–5% swing at 24–36 months |
| Efficiency ratio | Multifamily Executive (82–85% commercial, 70–75% apartments) | Single undated trade article; no institutional dataset exists |
| Soft cost % | HUD MAP (4% working capital, 10% BSPRA) + RAND split | HUD figures are underwriting limits, not market observations |
| Fees | Duncan 2019 (5 land uses, multi-state) + Terner (CA) + CA HCD schedules | Duncan 7 years stale and discontinued; Terner CA-only |
| Contingency | AACE 18R-97 (Class 5 −50/+100; Class 4 −30/+50) | 18R-97 says ranges must come from project-specific risk analysis and never be pre-set; it justifies a range but supplies no number |
